# Code of Conduct

## Our Standards

Determinex is a technical project. We expect contributors to:

- Be direct and specific in technical discussions
- Accept that compiler output and benchmark scores are ground truth — not opinions
- Give and receive blunt feedback on code quality without taking it personally
- Stay on topic: this is a code generation / AI tooling project

We do not tolerate:
- Harassment, personal attacks, or discriminatory language
- Spam, self-promotion, or off-topic noise
- Filing duplicate issues or ignoring the issue template requirements

## Enforcement

Violations are handled by the maintainer. First offense: warning. Second offense: ban.

## Contact

Open a [GitHub issue](https://github.com/determinex-ai/determinex/issues) or contact the maintainer via GitHub.
