#      "bit-for-bit reproducible", so following that instruction produced an environment missing 31

#      the additions from the 2026-07-16 CVE remediation. It now resolves the complete closure.
#   2. Three pins sat BELOW the security floors requirements.txt declares -- cryptography 43.0.3
#      (floor 48.0.1, GHSA-537c-gmf6-5ccf), torch 2.5.1 (floor 2.13.0, CVE-2025-3000) and litellm
#      1.52.3 (floor 1.84.0) -- so the documented production path installed known-vulnerable
#      versions. Verified against every declared floor at generation time: 0 below.
#

# on any dependency declared in requirements.txt that this file omits. Neither can rot silently.
