# Public Disclosure Freeze Checklist

**Status:** active draft checklist
**Prepared UTC:** `2026-06-02T22:31:15Z`

## Freeze Rule

Do not publish invention-enabling details before filing review and explicit operator approval.

## Before Any Public Disclosure

- Attorney review completed.
- Filing decision recorded.
- Public copy reviewed for patent-sensitive enabling detail.
- Public claims scanner passes.
- Day-one public claim scanner passes.
- Public release go/no-go remains explicit.
- Patent-sensitive diagrams reviewed or withheld.
- ProgramBench claims use canonical board truth only.
- Cloak claims cite final publishable audit only.
- Release readiness, family support, clean-host proof, and signing/trust claims remain gated.

## Public Materials To Review

- `README.md`
- `CLAUDE.md`
- `CHANGELOG.md`
- `docs/WHITE_PAPER.md`
- `docs/ARCHITECTURE.md`
- `docs/papers/*`
- `docs/public/*`
- demo scripts
- launch posts
- investor/funder summaries

## Non-Claims

This checklist does not make a filing decision and does not authorize publication.
