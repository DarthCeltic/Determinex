# Invention Claim Boundary

**Status:** draft boundary notes
**Prepared UTC:** `2026-06-02T22:31:15Z`

## Safe Internal Description

Determinex is a local-first agent system that uses deterministic compiler/test feedback, proof artifacts, and gated claim boundaries to turn coding failures into structured training data while protecting proprietary identifiers when cloud models are used.

## Boundaries To Preserve

- Compiler/test pass is not product release readiness.
- Exact release-supported cells are not broad family support.
- Local installer launch is not clean-host proof.
- Signed packet readiness is not signed/trusted distribution.
- Proof Center source code is not installed-app Proof Center smoke.
- Segmented status validation is not a full `tests/status` pass.
- Known-world accounting is not universal support.
- ProgramBench locks are exact per-tool outcomes, not total benchmark completion.

## Forbidden Public Phrasing Before Filing

- "patented" or "patent pending" unless actually filed.
- "public release ready" unless the release go/no-go packet passes.
- "universal support" or "all families supported".
- "fully private cloud AI" without the final publishable Cloak audit.
- "clean-host proven" without materially distinct clean-host evidence.

## Review Needed

Attorney review is required before any external publication, investor packet, public demo script, or launch copy uses these invention themes.
