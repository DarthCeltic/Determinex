# Determinex Model Notices

Determinex source distribution does not bundle proprietary model weights.

Local model use is operator-provided and separately configured. Model files,
provider API keys, benchmark datasets, and third-party checkpoints are not
granted release approval by this notice. Operators are responsible for complying
with the license and usage terms of any model they install or connect.

The release gate treats model notices as a public-distribution hygiene check, not
as a claim that every optional model backend is admitted, benchmarked, or
redistributable.
