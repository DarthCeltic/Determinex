# Unified Product Splash Demo Spec

> Locked under
> `locks/sentinel/DETERMINEX_UNIFIED_PRODUCT_SPLASH_DEMO_SPEC_LOCK_001.json`.

5-step release splash demo, one step per product surface. Shows
Determinex **does it all responsibly** without claiming unsupported
universality.

## Five steps

1. **Idea Lab** — beginner idea → spec → blueprint → scaffold → tests → smoke plan
2. **Repo Clinic** — diagnose & verifier-gated repair on a fixture
3. **Maintenance Bay** — proposed dependency update under compatibility verifier (blocked path)
4. **Learning Studio** — explain failure / teach the fix in beginner / pro mode (teaching moment)
5. **Proof / Operator Center** — evidence, gates, blocked actions, training False (proof view)

## Required copy

| Required string |
|---|
| **`Proof Before Mutation`** (tagline) |
| **`Generated is not verified.`** |
| **`Working means build/test/smoke passed.`** |
| `not all apps` |
| `not all languages` |
| `not production-ready arbitrary apps` |
| `not training enabled` |

## Hard rules

| Rule | Refusal |
|---|---|

| Required phrase or negative caveat missing | `BLOCKED_FALSE_UNIVERSALITY` |
| Sequence is not one step per surface in canonical order | `BLOCKED_AUTHORITY_CONFUSION` |
| No blocked-path step | `BLOCKED_AUTHORITY_CONFUSION` |
| No teaching step | `BLOCKED_AUTHORITY_CONFUSION` |
| No proof view step | `BLOCKED_MISSING_PROOF_VIEW` |
