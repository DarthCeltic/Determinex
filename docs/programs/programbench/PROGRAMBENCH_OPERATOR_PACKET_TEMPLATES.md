# ProgramBench Operator Packet Templates

`PROGRAMBENCH_OPERATOR_PACKET_TEMPLATES_LOCK_001` writes reusable JSON-compatible templates for operator-supplied evidence.

The templates cover security policy admission, image metadata, operator provenance, pinned base digest, original build recipe, bounded rerun authorization, scanner admission, and artifact import provenance.

The Doxygen security template is bound to `programbench/doxygen_1776_doxygen.966d98e:task_cleanroom` and digest `sha256:cc50d0f7e9a1f3f90512e3d4c34781f4686a8fa3774fbff489947ef41bde2e72`, and references the scan, sandbox, and exception-request evidence.

Templates are not approvals and do not authorize execution or training eligibility.
