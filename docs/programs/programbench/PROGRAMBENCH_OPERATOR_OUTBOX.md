# ProgramBench Operator Outbox

`PROGRAMBENCH_OPERATOR_OUTBOX_LOCK_001` writes fillable packet templates to `assurance/operator_outbox/programbench/`.

The outbox contains a README, a manifest with hashes, the Doxygen security policy admission template, and Batch 001 image metadata templates.

Operators fill and sign templates, then place completed packets in `assurance/operator_inbox/programbench/`.
