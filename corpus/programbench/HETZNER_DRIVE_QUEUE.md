# Hetzner Drive Queue — not-locked tools, xrayed + laned

> Generated by joining `eval_index.json` (board truth) + `xray_index.json` (spec cross-check)
> + Hetzner shim inventory + local `per_tool_overrides` recipes.
> **Locked (official_full_suite_resolved=true): 65. Certified/confirmed ceilings: 30. Drivable below: 125.**

**Eval command (Hetzner):** `cd /root/ProgramBench && PYTHONUTF8=1 uv run programbench eval <pilot_dir> --filter <author> --force`  
**Always `docker rmi -f programbench-compiled/<slug>:determinex-cached` before re-eval.** Archive a lock only when `passed==total, not_run==0, skipped==0, failed==0`.

## Driver protocol (per tool, in lane order — cheapest first)

1. **Resolve the shim.** `have=shim` → eval the existing pilot dir on Hetzner. `have=recipe`
   → build submission from `corpus/programbench/per_tool_overrides/<slug>/compile.sh`, scp to
   Hetzner, eval. `have=build` → no recipe yet; for lanes A/B/C/D pull the canonical eval
   report + `tests.json` and run `determinex_xray.py --report ... --tasks-dir ...` to confirm the
   lane, then build a recipe; for lane E hand to the reimpl build program.
2. **`docker rmi -f programbench-compiled/<slug>:determinex-cached`** (cache is stale otherwise).
3. **Eval**, read the produced `eval_report.json`.
4. **Decide:** `passed==total & 0 not_run/skip/fail` → archive lock (eval_report.json +
   submission.tar.gz + source/ + lessons.md), set `official_full_suite_resolved=true`,
   run `pb_override_scan.py --guard`. Else → re-xray the new report, it will re-lane itself.
5. **Note on lane A:** rows at `official%=100` are claimed strict_locks missing only the
   `official_full_suite_resolved` flag — one confirming eval sets it. Rows at low official%
   (brotli 4.4, quinn 7.8, bedtools 0.37) are genuine stale-board wins — same one eval locks them.

> Regenerate this queue any time: `python scripts/determinex_xray.py --all <reports> --tasks-dir <tasks>`
> then re-run the join (eval_index + xray_index + shim/recipe inventories).
